# 房屋计费依据批量导入实施计划

依据：[已确认方案](../design/20261028-fee-basis-import.md)。范围仅为物业后台已有房屋的依据版本导入，实施顺序为共享写入规则 → 导入适配与前端接入 → 集成验证 → 手册与契约同步 → 交付。

## 任务拆分与依赖

- [x] 核对已确认方案、工程规范与现有导入机制，建立专用工作区及独立分支。
- [x] 提取手工与导入共用的依据校验及事务参与式追加能力，保持手工接口行为。
  - 同月最新版本比较，数值规范化，原因与内容相等判断分离。
  - 固定目标、位置快照及全房屋版本基线，明确新执行与原成功复用。
- [x] 新增 v1 固定模板、注册及导入适配。
  - 已有房屋定位、每房一行重复检查、条件必填和精度校验。
  - 准备快照、包含基线的操作身份、逐行事务和未知结果恢复。
  - 安全预览投影，显示同月旧值、新值、差异、月费与生效区间。
- [x] 接入物业后台新建入口、权限判断、说明及预览展示。
  - 仅依据维护角色可完成处理；仅账务读取角色可读不可写。
  - 保持已有导入类型与平台边界，不将月费汇总为应收。
- [x] 补齐并执行规则、API、真实 PostgreSQL 并发与恢复测试。
  - 验证相同跳过、差异追加、A→B→A、跨月节点及既有账单不变。
  - 验证重复行、停用与越界、预览后版本或位置变化、幂等及未知结果。
- [x] 同步相关手册与 OpenAPI 业务说明，保持旧模板版本和摘要。
- [x] 完成格式、Lint、类型、契约及相关回归，评审最终变更。
- [x] 完成后台浏览器关键链路验收，核对标准视口及权限入口。
- [x] 核实交付结果，冻结方案并结案本计划；未完成条件与限制如实保留。
