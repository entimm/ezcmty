# 测试运行准备优化实施计划

## 范围与依赖

按[后端测试运行准备](../../architecture/test-runtime.md)实施数据库模板复用和普通业务账号准备优化。保持真实迁移、认证、审计、事务、并发及大数据验证，暂不增加并行测试依赖或改变进程数。

## 实施顺序与验收

- [x] 保存当前提交、用例清单和可比较的优化前耗时证据；准备、执行、清理分别计时，重复代表性样本。
- [x] 实现每轮已迁移空库模板、每用例独立克隆、异常清理；迁移专项继续从空库运行。通过隔离、真实提交/回滚及清理验证后完成此项。
- [x] 增加业务专用账号及会话准备能力；逐类切换普通业务用例，保留认证、密码、审计和相关事务专项的完整流程。通过真实权限、租户、CSRF、会话失效验证后完成此项。
- [x] 执行必要格式、Ruff、mypy 和完整回归；核对有效用例覆盖与零失败、零跳过，修复本次改动导致的问题。
- [x] 使用一致用例集合复测，报告耗时变化及测量限制，更新操作文档与本计划。

## 完成条件

共享测试准备能力有有效回归保障，全部必要检查通过；交付实际耗时证据和遗留限制。完成首批后停止，不自动引入并行执行。
