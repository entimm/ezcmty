# 物业业务共享能力实施计划

依据：[已确认设计](../design/20261029-property-business-sharing.md)。状态：已结案。

已完成本期代码、迁移与验收；范围不包含部署或真实渠道操作。

## 范围与依赖

实施范围以设计为准：数据库仅替换三处外键，前后端提取共享物业业务能力，并保持现有物业后台与导入行为。平台和小程序接入不在本期范围。

| 阶段 | 内容                     | 依赖                         | 完成条件                                         |
| ---- | ------------------------ | ---------------------------- | ------------------------------------------------ |
| A    | 实施准备与基线           | 实施授权                     | 明确本期差异、调用方和回归范围，具备专用工作区   |
| B    | 三处外键调整             | A                            | 真实数据库升级及降级验证通过，结构差异无扩展     |
| C    | 后端共享提取             | A；C4 依赖 C1，C2/C3 依赖 C1 | 物业与导入调用共享能力，保留授权、事务及恢复边界 |
| D    | 后台页面共享提取         | A；按业务与 C 对齐           | 物业入口注入运行能力，页面与请求行为保持兼容     |
| E    | 综合验证与评审           | B、C、D                      | 设计验收条件及相应工程门禁满足                   |
| F    | 手册与契约同步、交付结案 | E                            | 现行文档反映实际交付，方案冻结，计划按实结案     |

B 与 C 可分别准备，D 不依赖新增公共接口；合并交付前必须共同验证。后端、前端和迁移应作为本期一致变更评审，不以局部完成替代整体验收。

## A. 实施准备

- [x] 取得本期代码及迁移实施授权，核对已确认设计与现行工程、前端、API、数据库及测试规范。
- [x] 按开发规范建立专用 worktree 和独立分支；检查已有任务工作区，避免重复创建或覆盖其他改动。
- [x] 核对物业接口、现有权限、四类导入创建、审计、页面入口及历史请求恢复基线，确定受影响调用方和有效回归用例。

验收：范围与设计一致，不引入平台、小程序接入或无关重构；既有工作内容得到保留。

## B. 数据库迁移

- [x] 新增一个 Alembic 增量迁移，同步持久模型，仅按设计替换三处操作者外键；保留其他结构和既有迁移。
- [x] 实现降级兼容检查；有非空操作者与业务公司不一致的历史时拒绝降级，不删除或改写数据。
- [x] 在隔离 PostgreSQL 验证空库建库、已有数据升级、模型结构一致性、兼容数据降级及不兼容数据拒绝降级。
- [x] 验证有效业务记录可引用无公司平台账号，悬空账号仍被拒绝；空操作者的合法状态、公司及业务关联、资金与不可变保护继续有效。

验收：数据库差异严格限定为设计中的三处外键，字段、索引、其他约束和触发器保持不变，无数据回填或历史改写。

## C. 后端共享能力

### C1. 上下文与共同创建

- [x] 建立共享物业业务模块和普通业务上下文，区分真实操作者、认证来源、目标范围及已核验业务能力。
- [x] 将房屋、业主、计费依据、账单四类现有创建能力迁入共享模块，保持各自职责，更新物业及导入调用方。
- [x] 保留端内认证、权限和范围解析、写入前重验与提交回滚；清除共享能力对物业会话和固定物业身份的依赖。
- [x] 验证上下文不能由外部请求覆盖；手工和任务均在当前授权与统一事务保护下执行，不新增隐藏提交或重复业务实现。

### C2. 房产与业主

- [x] 提取房产查询、空间维护、房屋及业主更新，保留目标公司过滤、完整位置和启停校验。
- [x] 物业端应用编排完成适配，复用现有输入输出转换与错误语义。
- [x] 验证原物业查询维护、越界、停用和手工与导入竞争；验证业务与审计共同回滚。

### C3. 计费依据、账单与线下账务

- [x] 提取依据与账单读取、试算、修改、收款、纠正、撤销、作废以及操作结果核验与恢复。
- [x] 保留既有金额、版本、支付占用、锁序、重复月账单和重复冲正保护。
- [x] 保持幂等键范围、输入摘要、操作者匹配、首次结果与历史结果格式，验证提取前请求仍可恢复。
- [x] 验证并发建账、重复收款、版本冲突、初始收款权限、支付占用和未知提交结果；同时覆盖手工与导入调用。

### C4. 认领、绑定与操作者展示

- [x] 提取认领及绑定查询、审核与撤销，保持权限、状态版本、原因、用户与房屋可用性校验。
- [x] 验证批准与绑定创建、驳回、撤销及审计的原子性，以及与撤回、解绑等既有操作的竞争。
- [x] 按真实身份记录来源、操作者及目标公司；名称读取仅从已授权业务关联账号取得，移除操作者必须同公司的展示限制。
- [x] 验证人工与系统展示准确，不开放任意账号或平台管理日志读取，不扩大现有日志权限。

后端验收：满足设计的共享依赖及事务边界；四类现有导入的预检、成功复用、执行时撤权、目标变化、失败重试、租约接管及未知结果恢复通过。

## D. 后台前端共享能力

- [x] 新增共享物业业务模块，迁入对应房产、账单、依据、认领、绑定页面及关联表单和展示；类型复用生成契约。
- [x] 定义本期实际使用的业务 API、动作判断、范围、查询身份、导航及草稿保护能力，由物业入口注入。
- [x] 保留物业请求适配、壳层及页面开放规则；共享页面解除对物业会话、物业路径拼接和固定权限前缀的直接依赖。
- [x] 将账单待恢复提交改为业务动作与原目标描述，由本端适配生成请求；保持请求体、输入摘要和原幂等键兼容。
- [x] 统一共享页面的查询身份及范围清理，验证缺少范围不查询、详情归属核实、迟到响应隔离、切换范围和未保存保护。
- [x] 保持公司资料、工作台、系统、支付及导入模块所属职责；不增加平台或小程序占位入口。

前端验收：现有物业入口完成共享页面的运行能力注入，关键业务、导航、反馈、冲突和未知结果恢复保持一致。

复用现有有效测试，按新边界补充缺口，不为目录迁移机械重写测试。执行要求与稳定入口见[测试规范](../handbook/standards/testing.md)及[检查与验证](../handbook/development/verification.md)。

- [x] 真实 PostgreSQL 迁移、约束、事务、并发与恢复专项通过；涉及会话及任务协调的保证按需使用真实 Redis 验证。
- [x] 核对现有平台、物业和客户端身份隔离；物业公司范围与权限保持不变，写入等待期间撤权或停用仍阻止无权写入。
- [x] 四类导入及既有物业手工业务回归通过，历史幂等结果、固定输入与成功事实可继续恢复。
- [x] 管理后台格式、Lint、类型、边界、相关测试和构建通过。
- [x] 按前端规范在浏览器验收房产、账单与收款、认领与绑定的代表链路，覆盖标准视口、至少两种主题及标准和紧凑密度，保留可复核附件。
- [x] OpenAPI 检查、类型生成及逐运行端契约一致性通过，接口集合、请求响应、错误、安全要求及运行归属未扩大。
- [x] 评审最终差异：共享不反向依赖端内实现，无重复业务规则，无新增主要依赖、公共接口、平台菜单或小程序接入。
- [x] 根据实际交付阶段补齐规范要求的完整门禁，如实记录通过、失败及未执行范围，不以局部回归代替完整验收。
