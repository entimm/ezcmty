# 房屋批量导入实施计划

依据 [房屋导入设计](../../design/property/house-imports.md)、[共享建房能力](../../design/property/housing.md#共享建房能力)、[空间路径定位与复核](../../design/property/housing.md#空间路径定位与复核) 及 [通用导入架构](../../design/imports/architecture.md) 实施，业务规则以这些文档为准。

设计确认及计划落盘不构成代码实施授权。获得实施指令后按依赖顺序执行；每项完成并验证后才勾选，未执行、失败或跳过不得计为通过。仅授权部分阶段时，完成该范围后停止，不部署或导入真实业务数据。

## P0：基线与契约核对

- [x] P0-01：建立实施分支，检查手工房屋、共享定位及导入框架的代码和测试基线，限定本次改动范围。
- [x] P0-02：核对现有导入契约对房屋类型、范围、受控预览、问题及行结果的表达；需要补充的错误或契约按 OpenAPI First 先行维护及生成派生产物。
- [x] P0-A1：明确手工房屋契约兼容要求和所需检查命令，不扩展自动建空间、业主导入、更新或覆盖能力。

## P1：共享空间路径能力

- [x] P1-01：依赖 P0，在房屋领域提取普通空间位置输入、按 ID 或完整路径定位、结构化快照和原节点复核，Repository 负责范围过滤与锁后刷新。
- [x] P1-02：既有完整房屋定位复用适用的空间路径能力，保留房屋辅助编号核验和原房屋 ID 复核语义。
- [x] P1-A1：验证层级组合、精确匹配、空层级、前导零、缺失空间、跨范围及路径变化；账单定位与导入相关回归通过。

## P2：共享建房与手工兼容

- [x] P2-01：依赖 P1，提取普通建房命令、规范化、业务校验、权限需求、自然键及当前基础资料比较，不依赖导入类型或 HTTP Schema。
- [x] P2-02：提取参与调用方事务的建房编排、房屋与初始业主写入和业务审计，共享能力不提交或回滚事务。
- [x] P2-03：手工新增调用共享能力，保留请求响应、重复创建冲突、多业主原子性、条件权限及显式字段审计。
- [x] P2-A1：手工房屋与业主回归通过；校验和写入只有一份业务实现，普通命令不携带导入标识。

## P3：模板与薄适配器

- [x] P3-01：依赖 P2，发布不可变 `houses` 模板和适配器注册，仅允许物业端、小区范围和创建模式，不包含业主或自动建空间输入。
- [x] P3-02：实现协议转换和准备数据持久化；业务身份独立于其他字段有效性，文件内重复覆盖全部同身份行。
- [x] P3-03：预检、执行及结果复用共同调用共享能力；当前资料一致跳过、不同冲突，固定路径和已有目标，沿用逐行事务及原操作恢复。
- [x] P3-A1：CSV/XLSX、严格列校验、无业务副作用预检、当前资料判重、跨批次竞争、失权阻断、固定输入重跑及未知结果验证通过。

## P4：管理后台入口与预览

- [x] P4-01：依赖 P3，在小区房屋列表接入通用导入向导，固定类型及当前小区，按目标详情显示范围名称。
- [x] P4-02：展示受控房屋业务预览、动作及问题，说明空间须提前建立、文件不携带业主和整小区范围；完成后返回列表并刷新缓存。
- [x] P4-A1：验证入口权限、空间树筛选不误导范围、预览确认、问题修复提示、部分失败、取消及返回列表。

## P5：整体回归与交付

- [x] P5-01：依赖 P0–P4，以隔离 PostgreSQL 验证两个入口及跨批次并发、唯一约束、完整原子提交与回滚、路径及目标变化和恢复历史。
- [x] P5-02：执行受影响的手工房屋、业主、账单定位、账单导入、通用导入和 Worker 回归；安装 wheel 后脱离源码验证模板、摘要及适配器加载。
- [x] P5-03：完成相关后端与前端格式、Lint、类型、测试、构建、各运行端契约及文档引用检查，维护必要派生产物。
- [x] P5-A1：按测试规范区分通过、失败、跳过及未执行，报告关键保障和遗留风险；核对改动范围后停止，不自行进入下一阶段。
