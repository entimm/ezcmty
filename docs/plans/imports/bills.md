# 账单批量导入实施计划

依据 [账单导入设计](../../design/property/bill-imports.md)、[共享建账能力](../../design/property/billing.md#共享建账能力)、[房屋完整位置定位与复核](../../design/property/housing.md#房屋完整位置定位与复核) 及 [通用导入架构](../../design/imports/architecture.md) 实施，业务规则以这些文档为准，不在本计划重复定义。

设计确认及计划落盘不构成代码实施授权。获得明确授权后按依赖顺序执行；各项完成并验证后才勾选，未执行、失败或跳过不得计为通过。只授权部分阶段时，完成该范围后停止，不部署或导入真实业务数据。

## P0：契约与错误准备

- [x] P0-01：建立实施分支及检查基线；先明确 OpenAPI 中受控业务投影、完整执行集合财务汇总、条件权限和结果表达，再实现运行端消费。
- [x] P0-02：维护业务错误映射、契约版本和派生产物，保持原手工建账请求响应契约兼容。
- [x] P0-03：落盘准备快照保护迁移设计，限定未确认普通批次在新预检版本更新快照，保留其他不可变保护。
- [x] P0-A1：OpenAPI lint、bundle 通过，新增投影、错误及阻断语义明确，未将内部命令或准备快照直接开放给前端。

## P1：共享房屋能力

- [x] P1-01：依赖 P0，按房屋领域设计实现普通位置输入、逐级定位、可选辅助编号核验、位置快照和原房屋复核，不依赖 HTTP 或导入类型。
- [x] P1-02：复用既有归属、启停及锁序能力，不在账单或适配器中复制位置匹配规则。
- [x] P1-A1：验证有无分区及单元、空层级、前导零、跨小区同名和辅助编号边界；位置变化后复核拒绝改绑。

## P2：共享建账与手工兼容

- [x] P2-01：依赖 P1，从现有手工建账提取普通命令、只读校验、条件权限需求、原始创建事实比较及统一写入，业务层不依赖导入框架。
- [x] P2-02：初始收款复用现有入账能力，业务操作、结果快照和逐账单审计通过公共记录能力写入；共享调用链不提交或回滚事务。
- [x] P2-03：手工新增先改为调用共享能力，保留自动计算、旧请求指纹、首次响应快照及显式输入字段的审计语义。
- [x] P2-A1：手工建账及原键恢复回归通过，建账与初始收款规则只有一份实现，普通命令不携带导入类型、批次或行号。

## P3：最小通用协议保障

- [x] P3-01：依赖 P2，显式返回并持久化准备结果及计划；区分未确认重新预检与确认后的恢复、失败重跑，后两者固定原准备输入和操作身份。
- [x] P3-02：补齐数据准备后的条件权限及成功、跳过结果复用前的权限和业务目标核验，保持通用框架不识别账单字段或业务规则。
- [x] P3-03：新增 Alembic 迁移受控调整 `import_guard_history`，不改旧迁移；验证普通重检允许、同版本及已确认/重跑/终态改写拒绝和升级回退。
- [x] P3-A1：验证失权整批阻断且不可经 `valid_rows_only` 绕过；重跑不改绑、不换输入，当前条件变化不抹除原成功事实。

## P4：账单模板与薄适配器

- [x] P4-01：依赖 P3，发布不可变账单模板，完成物业端类型、版本及适配器注册；适配器仅转换输入、普通业务结果与导入协议。
- [x] P4-02：预检及执行调用共享房屋、建账和记录能力；通过原有稳定操作身份关联业务幂等，逐行事务包含业务与导入结果，不复制业务规则。
- [x] P4-A1：日常与历史场景、初始已缴必填含零、重复及冲突按设计执行；成功重复不再次收款，作废目标不自动重建。

## P5：管理后台入口与预览

- [x] P5-01：依赖 P4，在小区账单列表接入向导并锁定类型及小区，通过目标详情读取范围名称，不依赖第一页选项；完成后返回账单列表并刷新缓存。
- [x] P5-02：显示匹配位置、动作及问题，按服务端完整执行集合展示财务合计；策略与警告选择变化更新合计，确认明确提示创建即生效。
- [x] P5-A1：验证权限、范围、分页汇总、异步失效和返回流程，首次成功快照不会覆盖账单后续变化。

## P6：整体回归与安装制品

- [x] P6-01：依赖 P0–P5，按 [测试规范](../../conventions/testing.md) 完成分层验证，以隔离 PostgreSQL 覆盖两个入口并发、原子提交与回滚、重导、重跑、未知结果及历史稳定。
- [x] P6-02：执行手工账单、线下收款、支付占用、线上入账、通用导入及 Worker 回归；独立安装 wheel 验证定义、摘要、适配器及保留版本加载。
- [ ] P6-03：同步受影响文档与派生产物，执行后端和前端格式、Lint、类型、测试、构建、各运行端契约及项目完整门禁。
- [x] P6-A1：明确启用所需真实依赖测试；逐项报告通过、失败、跳过、未执行及遗留风险，核对改动范围后停止，不自行进入下一阶段。
