# 管理后台业务权限实施计划

## 范围与依据

依据 [业务权限与岗位模板设计](../../design/admin/authorization.md)，合并底层原子权限，提供业务模块授权、六类岗位模板及物业本公司账号角色管理入口。无需历史角色、权限数据迁移或旧权限码兼容。不扩展指定小区授权、角色继承、模板升级同步或基础设施。

本计划区分正式设计与代码实施。设计确认和文档落盘不代表代码实施授权；实施授权遵循 [设计工作流](../../standards/documentation.md#设计工作流)。完成并验证后才勾选对应事项。

## 任务与依赖

### 一、设计与契约准备

- [x] 落盘业务权限、模板、物业管理入口及工程保障设计，同步相关业务文档并通过引用和一致性检查。
- [x] 代码实施前检查现有附件并创建或复用本实施任务的专用 worktree 和独立分支；保留当前工作区变更。
- [x] 按新目录逐项清点路由、API、Service、共享业务能力、导入配置、Worker、种子数据及前端调用方，明确替换范围。
- [x] OpenAPI 先定义合并后的权限码和各端操作声明，覆盖固定依赖、权限目录及模板所需信息、一次创建角色和初始授权、影响账号及最终权限预览、本公司账号角色和日志接口。
- [x] 契约明确基础上下文、账单最小房屋查询、关闭页面所用公司和小区资料的字段及授权，不因缺少旧查询权限造成断链或扩大明细读取。
- [x] 更新契约版本和所需派生文件，通过 API 格式、引用及契约静态检查；实际运行端一致性在实现后验收。

验收：正式设计无相关冲突；每个既有入口有明确目标授权，新增物业管理和最小查询契约完备，未引入旧权限兼容层。

### 二、后端权限与管理能力

- [x] 用业务权限目录替换原子目录，统一固定查看依赖、可分配性及超级管理员系统管理能力，删除被替代的授权分支。
- [x] 同步平台接入、资金、核对及配置的授权；公司启停和资金异常处理单独校验。
- [x] 同步物业房产、账单、计费依据、收款及居民授权；普通经办不能执行未授予的关键操作。
- [x] 提供最小公司和小区上下文及账单房屋选项，保持公司隔离与必要字段投影。
- [x] 实现代码维护的本端岗位模板、创建角色及初始权限同事务提交，提供真实的角色影响范围和账号最终权限信息。
- [x] 在物业进程注册本公司账号、角色和日志接口，限制系统管理写入，复用并验证公司锁序、最后一个有效超管保护、审计和会话撤销。
- [x] 同步开发种子和测试工厂，按新目录生成独立角色与授权；不执行既有环境清库或数据重置。

依赖：第一阶段契约准备完成。验收：后端权限单元、相关共享能力与双端管理集成测试通过，真实 PostgreSQL/Redis 覆盖事务、会话和并发边界。

### 三、导入完整流程

- [x] 移除独立导入动作授权，按具体导入类型的业务查看和维护权限统一控制目录、批次、文件、预检、确认、取消、失败重跑及原任务恢复。
- [x] 统一错误文件生成和下载的读取授权、投影、保留期和 CSRF；类型注册及跨端限制保持有效。
- [x] 适配器、共享能力、每个执行分块及成功结果复用使用当前业务权限；带正金额初始收款仍单独要求收款登记。
- [x] 验证普通维护角色完成房屋、业主和账单导入，查看角色不能执行导入，缺少收款权限、撤权和跨公司访问被阻断。
- [x] 回归固定目标、租约、取消、未知结果、幂等及原任务恢复，确认权限简化未改变业务状态或恢复语义。

依赖：第二阶段共享权限与业务授权完成；可与对应业务实现交叉推进。验收：导入集成及 Worker 回归通过，无旧导入权限引用。

### 四、双后台配置与使用体验

- [x] 同步路由、菜单、命令搜索、查询和按钮，依据合并权限开放页面，保持现有关闭页面开关与公司范围。
- [x] 角色配置替换为模块级别及关键操作，展示自动包含项、业务能力摘要和真实影响账号。
- [x] 实现选模板、调整、预览和一次创建；普通角色更新后与模板独立，不提供模板同步机制。
- [x] 账号分配角色时展示最终权限并集，避免移除一个角色后误报能力已经撤销。
- [x] 新增物业系统管理入口，复用本端账号、角色及日志界面；只读权限不显示写入口。
- [x] 建账使用最小房屋选项，收款字段按登记权限开放，导入入口跟随目标业务，页面不再按旧原子权限隐藏必要步骤。
- [x] 通过针对模板、依赖、关键操作、双端隔离、权限变化与失败恢复的前端流程检查。

依赖：契约和对应后端能力可用。验收：六类模板的实际岗位流程可用，授权摘要和页面行为一致，系统角色保护明确，无模板或预览模拟数据进入产品。

### 五、综合验收与交付

- [x] 检查源代码、契约、测试、种子及长期文档中的旧授权项和规则，区分审计操作名与权限码，保留具体操作审计。
- [x] 运行相关格式、Lint、类型检查、前后端测试及所有受影响运行端的 API 契约一致性检查。
- [x] 使用真实 PostgreSQL/Redis 验证物业管理隔离、并发超管保护、角色授权与审计事务、撤权会话和导入执行复核。
- [x] 核对模板岗位能完成规定工作、敏感动作默认不授予、公司范围不扩大、最小查询不泄露业主信息。
- [x] 更新实际变化的契约和操作指南，报告检查结果、跳过或未执行项及剩余限制；完成本主题后停止。

依赖：前四阶段完成。验收遵循 [测试规范](../../conventions/testing.md) 和各业务设计，不以测试替身或跳过真实依赖代替通过。
