回退边界：根路径静态发布只回退独立 IP 产物软链接及相关静态 Nginx 配置；首次切换恢复原共享静态 root 和页面路由，后续恢复上一完整产物对，不切后端 `current` 或域名产物。撤除整个 IP 入口时才按指南恢复本次相关 Origin、IP 证书任务和防火墙规则，不删除既有证书、不变更原 DNS 流程、不回退数据库。详细执行证据、配置备份与日志保留于受控位置，不将敏感内容写入本计划。
