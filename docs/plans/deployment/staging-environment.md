# 测试服务器基础环境实施计划

范围：通过 SSH 别名 `xcmty` 搭建已确认的原生测试服务器环境。部署边界见[部署约定](../../architecture/deployment.md#测试服务器基础环境)。本阶段不发布应用、不创建业务库、不执行迁移或 seed、不开放支付。

- [x] 只读盘点系统、资源、SSH 与 sudo、已有服务、监听端口、账号和目录；确认 Ubuntu 26.04、Python 3.14、2GB swap 及原生软件源候选版本。
- [x] 安装 Nginx、PostgreSQL 18、Redis、Python venv、uv 和证书维护工具；验收版本和组件可用性。
- [x] 创建专用运行账号与发布、配置、状态和受限备份目录；验收属主、权限与账号无 sudo 权限。
- [x] 配置本机数据库和 Redis、保守内存参数及日志容量；变更前保存原文件，配置检查后启动服务。
- [x] 在保留当前 SSH 入口的前提下配置 UFW，并用新的 SSH 连接确认可达；HTTP/HTTPS 入口为后续发布预留。
- [x] 验收 PostgreSQL 本机连接、Redis PING、Nginx 配置和默认拒绝站点、开机启动、监听范围、资源余量及无新增失败服务。
- [x] 补齐基础环境操作指南，检查文档格式、引用和改动范围；交付实际版本、验证结果及待部署事项。

依赖顺序：盘点 → 安装 → 账号与目录 / 组件配置 → 防火墙 → 综合验收 → 交付。现有 swap 复用，不重建；系统升级和重启仅在当前环境搭建确有必要时处理。既有失败服务仅记录，不扩展修复范围。
