# 空间、房屋与业主档案

物业在本公司小区内维护空间、房屋及业主登记。登记不等于居民身份或房屋授权，认领审批见[居民房屋授权](resident.md)。接口与输入边界见[房屋契约](../../../../openapi/modules/housing.yaml)。

## 层级与身份

```mermaid
flowchart LR
    C[小区] --> P[分区]
    C --> B[楼栋]
    P --> B
    B --> U[单元]
    B --> H[房屋]
    U --> H
    H --> O[业主登记：可多人]
```

分区、单元可省略；楼层是房屋属性。房屋只能直属楼栋或单元。

| 对象 | 唯一性与固定归属                                                             |
| ---- | ---------------------------------------------------------------------------- |
| 空间 | 同小区、同父级名称唯一，不按类型分开；小区、父级、类型创建后固定。           |
| 房屋 | 所属楼栋或单元内房号唯一；小区与所属节点创建后固定。                         |
| 业主 | 同房屋内姓名、规范化手机号组合唯一；所属房屋固定，同一人在不同房屋分别登记。 |

停用记录仍参与判重。名称、房号、楼层和外部编号可按契约修改；业务关联使用稳定标识，展示地址由当前小区、祖先名及房号组成。外部编号可重复、可清空，不作为实体身份。

## 输入与维护

- 节点名、房号、业主姓名去首尾空白后必填，保留内部字符和大小写。房号按文本保留前导零，不推算楼层或补写后缀；楼层可空、可为负数，排序非负。
- 外部编号去首尾空白，空白视为空，其余字符及前导零保留。编辑只处理显式字段，拒绝空更新、固定归属修改及必填字段置空，可空资料允许清空。
- 业主姓名和手机号同时填写；接受大陆11位号码及 `+86`、`0086` 前缀，统一保存不含前缀的号码。只校验格式，当前明文存储，不表示已验证；精确长度见[资料规格](../../../../openapi/components/housing-schemas.yaml)。

建房可附多名初始业主，房屋、全部登记和审计共同提交，任一失败回滚。后续业主独立维护，编辑房屋不替换业主集合。资料纠错用编辑；更换业主停用旧登记后新增，同组合重新登记时维护或启用原记录。

## 状态与读取

自身 `enabled` 与实际可用 `effective_enabled` 分开。实际可用要求小区、全部祖先和自身启用，业主还要求所属房屋可用；公司启用是物业访问前提。

| 情况                 | 处理                                                             |
| -------------------- | ---------------------------------------------------------------- |
| 停用上级             | 不改写下级自身状态；重新启用仍保留下级原状态。                   |
| 小区、空间或房屋停用 | 保留查询、资料修正和自身启停，阻止在该路径新增节点、房屋及业主。 |
| 空间筛选             | 树逐级分页，选中节点包含全部后代房屋；房屋不加入空间节点树。     |
| 档案列表             | 房屋和业主独立分页，业主按房屋读取，不因展开业主造成房屋重复。   |

房屋支持房号、外部编号准确匹配，以及楼层、自身启停筛选。列表与总数共享查询快照，空页仍返回准确总数。

## 定位、权限与一致性

- 按“分区（可空）→ 楼栋 → 单元（可空）→ 房号”逐级精确匹配；空层级表示不存在，不是通配。不拆展示地址、不猜房号、不取异常多候选中的首条，不创建缺失目标。
- 提供房屋外部编号时先完整定位，再与当前编号核验；不一致或当前为空均拒绝，不改选其他房屋。先定位后执行的流程固定原实体与位置快照，写入前复核路径、名称、房号及已提供编号；变化即停止，不按旧地址改绑。楼层等无关资料不单独构成位置变化。
- 完整档案读取要求 `property.housing.read`，新增、编辑及启停要求 `property.housing.manage`，包含本业务读取。账务最小选项不等于完整档案查看，不返回业主资料。
- 资源校验公司、小区及嵌套归属，越界按不存在处理。写入按公司、账号、小区、根到叶空间、房屋、业主的适用顺序协调，等待后复核权限及启停；唯一与复合归属约束兜底冲突，业务和审计共同提交，敏感原值不进日志及审计元数据。

- 普通档案编辑按最后成功提交的字段值生效，不具备账单版本冲突检查。
- 读取可重试，未知写入先核实原目标和结果，不自动重复创建、换标识或扩大范围；相同资料重复修改保持相同业务值，不表示未知创建可安全重发。
- 手工、导入、建账复用本篇规则，导入流程见[导入模块](../imports/README.md)。
