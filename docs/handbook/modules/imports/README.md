# 批量导入

固定模板的 CSV/XLSX 先形成完整预览，经确认后异步写入业务数据。当前只支持创建，不支持覆盖更新、任意列映射或整批回滚。

执行和幂等见[执行机制](execution.md)，数据与保留期见[数据及文件](data.md)。精确请求、响应和错误以 [OpenAPI 导入契约](../../../../openapi/modules/imports.yaml)为准。

## 当前类型与权限

生产注册三种模板 v1，均只属于物业后台、小区范围。公司取自登录身份，文件不能改变公司或小区。平台保留通用导入入口及接口，当前没有可用生产类型。

| 类型                            | 创建与判重                                                                                         | 处理 / 读取权限                                     |
| ------------------------------- | -------------------------------------------------------------------------------------------------- | --------------------------------------------------- |
| `houses` 房屋档案               | 在已有空间下建房；同节点同房号的当前楼层、外部编号一致则跳过，不同则冲突；不创建空间、不携带业主   | `property.housing.manage` / `property.housing.read` |
| `house_owners` 业主登记         | 向已有房屋登记业主；同房屋、姓名和规范化手机号组合跳过，停用登记不自动启用；登记不授予居民房屋权限 | 同上                                                |
| `property_fee_bills` 物业费账单 | 向已有房屋创建手填月账单，可登记初始收款；房屋、账单类型和月份确定身份，原创建事实相同则跳过       | `property.bill.manage` / `property.bill.read`       |

任一输入行的初始已缴可解释为正金额时，还要求 `property.bill_receipt.create`。即使该行其他字段有误、被策略排除或复用成功结果，也不能绕过；没有独立通用导入写权限。

读取、错误文件生成和下载使用目标业务读取权限。请求复核当前身份、后台和范围，先过滤可读类型再分页；历史读取不要求重新取得全部写权限。

## 模板规则

| 输入       | 规则                                                                                                                           |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------ |
| 位置       | 分区（可空）→ 楼栋 → 单元（可空）→ 房号逐级准确匹配；空层级不是通配符，保留大小写、前导零及内部字符                            |
| 房屋资料   | 楼层为可负整数或空，不从房号推算；外部编号是资料，不是身份；空值准确比较，不表示忽略                                           |
| 业主登记   | 姓名和手机号必填；大陆手机号接受 11 位及 `+86`、`0086` 前缀，统一保存为 11 位；允许一房多组登记                                |
| 账单       | 月份、原始应收、金额说明及初始已缴必填；支持历史、当前及未来月份，不用待缴余额替代原应收                                       |
| 金额和日期 | 元金额非负、最多两位小数，不带货币符号、不静默舍入；未缴填 `0`，已缴不超应收；收款日期不详可空，填写时不得为未来日期，说明可空 |
| 辅助编号   | 房屋外部编号只核验完整位置，不替代定位；外部账单编号不判重，也不回填其他档案                                                   |

建批固定模板版本与摘要。表头名称和顺序必须一致，拒绝未知列和重复列；原版本缺失或摘要漂移时阻断，不自动换用新版本。

## 预检与确认

```mermaid
flowchart LR
    A[选择类型和小区] --> B[建草稿并上传]
    B --> C[异步解析和预检]
    C --> D[完整预览]
    D --> E{显式确认策略}
    E --> F[逐行提交]
    F --> G[结果和问题]
    G --> H[错误文件或原任务恢复]
```

- 草稿只允许上传一次；修正文件需新建批次。解析和预检不写正式业务数据。
- 新预检期间旧预览失去确认资格，不提供半成结果或旧行结果；预览有效 24 小时且不超过输入保留期。
- `all_rows` 要求没有普通错误；`valid_rows_only` 显式只执行通过行。`include_warning_rows` 决定警告行，权限和范围等阻断条件不能跳过。
- 新增、跳过是计划动作，警告、错误是问题维度，不能相加为总行数。金额按完整新增集合汇总，分别给出含警告和不含警告结果，不用当前页求和。
- 离开页面不取消任务，异步受理不等于完成，取消不撤销已成功数据。

## 状态与结果

| 状态                                         | 含义                                                               |
| -------------------------------------------- | ------------------------------------------------------------------ |
| `draft`                                      | 待上传，创建 24 小时后失效                                         |
| `prechecking` / `preview_ready`              | 解析或预检中 / 可核对并确认                                        |
| `executing` / `blocked`                      | 按保存策略执行 / 原阶段暂停，未知结果先核实                        |
| `completed` / `partial_failed` / `failed`    | 无执行失败 / 有成功也有失败 / 失败且无成功；另按行查看策略排除结果 |
| `cancel_requested` / `cancelled` / `expired` | 等待安全停止 / 已停止 / 草稿或恢复窗口失效                         |

错误文件支持 CSV/XLSX，敏感值始终脱敏；结果变化使旧文件失效，需重新生成。解析失败尚无完整预览时只查询问题，不生成可修复行文件。
