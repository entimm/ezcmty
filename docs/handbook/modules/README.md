## 业务关系

```mermaid
flowchart LR
    A[账号与授权] --> P[物业公司与小区]
    P --> H[空间、房屋与业主]
    H --> B[计费依据与账单]
    C[微信账号] --> R[居民认领与绑定]
    R --> H
    R --> B
    B --> W[支付、分账与核对]
    I[批量导入] --> H
    I --> B
```

- 业主档案与居民访问授权分别管理，不能用手机号相同或导入成功替代房屋授权。
- 账单与支付分别维护应收和渠道资金事实，分账不是居民返利或物业费抵扣。
- 消费返利、积分、抵扣、商家业务和额外客户端业务身份当前没有生产业务入口，不列为已实现能力。
- 已实现能力、页面开放、依赖就绪与真实环境验收分别判断；具体边界归所属模块，不将替身测试视为真实渠道验收。
