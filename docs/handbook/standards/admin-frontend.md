# 后台前端规范

适用于平台、物业后台及共用组件。现行壳层与产品布局见[后台架构](../architecture/admin-web.md)，业务权限见[账号与授权](../modules/identity/README.md)，接口类型遵循 [API 规范](api.md#前端类型)。

## 开发与复用

- 开发前明确所属后台、业务域、公司或小区范围、读写权限、接口能力及页面模式。
- 复用现有壳层、组件、主题与数据请求机制；业务页面不另建导航、顶栏或小区选择器。
- 平台与物业用例不互相导入，不通过动态方式绕过边界；共用能力不反向依赖业务组装。
- 共用流程通过窄接口接收本端能力，不自行切换后台；依赖与公共能力提取按[开发规范](development.md)处理。
- 模拟数据只用于明确标识的预览或隔离测试；旧测试快照、模板与偶然实现不能变成新规范。

## 导航与上下文

- 路由、菜单、权限、搜索别名与页面开放规则集中维护，不在页面重复定义路径映射。
- 分组和主菜单沿用四字名称；标题、面包屑及快捷入口使用一致业务术语。
- 详情继承父菜单与返回入口；筛选和分页可恢复，筛选变化回首页，切换小区清理旧范围标识与选择。
- 菜单、快捷操作及命令搜索使用同一授权与页面开放判断，空分组隐藏；直达与登录回跳同样受保护。
- 小区作为物业业务上下文统一选择，不放普通筛选栏；公司范围页面明确不受小区切换影响。
- 无必要上下文时提供引导，不回退为公司或全平台查询；直达记录不能静默替换成其他小区对象。

## 视觉与列表

| 项目     | 要求                                                                           |
| -------- | ------------------------------------------------------------------------------ |
| 主题     | 继承主题与密度，强调色使用统一配置；身份色独立，状态不能只靠颜色识别           |
| 内容     | 复用页标题、面板、筛选栏和反馈；专属样式限定范围，不用全局覆盖修补单页         |
| 桌面     | 核对 1280×720、1366×768、1920×1080，主操作与分页可达，弹层随视口滚动           |
| 表格     | 先对象与位置，再状态、金额、时间和操作；宽表仅容器内滚动                       |
| 资源识别 | 优先名称与完整业务位置，UUID 用于精确定位和复制，不作为唯一识别信息            |
| 查询     | 仅发送契约支持的条件；仅查当前页须标明，不能将首 100 条当完整选项              |
| 分页汇总 | 使用真实分页和总数，汇总注明公司、小区或当前页范围                             |
| 金额     | 分与元明确转换，区分零、缺失和未知，不能推算已到账                             |
| 时间     | 时间戳展示、当前业务日及筛选统一北京时间，提交边界转换 UTC；纯日期和月份不偏移 |

日期、月份及时间范围使用相应选择器；按日范围采用起日零点至末日次日零点，遵守契约边界，审计保留精确时间区间。

## 表单与关闭规则

| 场景                             | 容器                           |
| -------------------------------- | ------------------------------ |
| 简单编辑、单次操作、轻量详情     | 弹窗，完成后刷新并保留查询条件 |
| 需要列表参照的侧览、审计或问题行 | 抽屉                           |
| 导入、复杂详情、持续跟踪流程     | 独立页面，仅真实阶段使用步骤条 |

- 字段有中文标签与就近校验，占位不能代替标签；仅校验当前模式，隐藏输入清理失效值。
- 以初始业务值判断修改：未改、空白或还原可直接关闭；清空原值仍是修改。
- 遮罩、ESC、关闭和取消执行同一规则；有未保存修改时在当前弹层提示继续或放弃，不叠加确认弹窗。
- 离开页面、前进后退、刷新和小区切换同样保护草稿；保存成功再导航，取消离开保留输入。
- 校验后提交，在途阻止重复提交和关闭；失败保留可修正输入，成功反馈实际结果。
- 危险操作说明目标、影响和原因；业务封装仍自行补齐版本、幂等及未知结果保障。
- 多步流程按真实状态推进，范围或资源变化后清理失效结果，不虚构进度。

## 请求、权限与反馈

- 查询须同时满足完整会话、页面开放、读取权限和必要范围，页面关闭不能阻断合法最小上下文。
- 请求与缓存隔离后台、用户、公司、小区和条件，组件不重复发起同一读取。
- 写入后刷新受影响查询；轮询有进行中条件、停止边界和失败反馈，不乐观显示资金成功。
- 身份失效时取消请求并清理数据与表单；旧响应不能回填新身份或范围。
- 未知写结果保留原请求身份与输入，先核实再恢复，不自动换键、换版本或重发。

| 状态                     | 用户应得到的信息                                         |
| ------------------------ | -------------------------------------------------------- |
| 加载、空、无匹配         | 区分原因及下一步，加载不能短暂显示空或旧范围数据         |
| 读取失败、无权限、不存在 | 明确说明，提供适用的重试、关闭或返回，不伪装空列表       |
| 校验、冲突、限流         | 定位可修正输入，保留草稿；先核对冲突，等待时间依据服务端 |
| 受理、处理中             | 显示真实阶段，总量未知不编造百分比                       |
| 完成、部分完成、未知     | 说明实际结果与安全下一步，不统一提示成功                 |

## 交付检查

- 路由、菜单、页面开放、权限及公司小区范围一致，无跨端调用或隐藏页查询。
- 核对长文本、至少两种主题和标准/紧凑密度；共享主题变化覆盖全部主题及两端代表页。
- 核对筛选返回、切区、草稿还原、忙碌关闭、重复点击、冲突和未知恢复。
- 状态有文字，图标有可读名称，焦点可见；采用锁定版本组件 API，不复制弃用写法。
- 页面与交互修改在浏览器验收，关键链路留可复核附件；按风险执行[相关检查](../development/verification.md)，如实说明限制。
